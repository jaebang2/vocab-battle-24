# 어휘 배틀 24 — 실시간 경쟁형 공개 웹사이트

사용자가 처음 제공한 **24개 어휘 문항/보기/정답을 수정하지 않고** `src/questions.js`에 보존했습니다.

## 기능
- 학생은 공개 링크/QR로 접속하여 별명 입력 후 참가 (회원가입 없음)
- 교사 진행 버튼으로 모두가 **같은 순서의 같은 문제**를 동시에 풀이
- 각 문제 25초 타이머, 25초 후 자동 정답 공개, 4.5초 후 자동 다음 문제
- 정답 시 기본 500~1,000점(속도 반영) + 연속 정답 보너스(최대 250점)
- 실시간 순위, 답변 인원, 개인 점수, 24문제 최종 순위
- **교사 비밀번호는 서버에서 확인**하고, 클라이언트에 노출되지 않음
- 교사 화면에서 학생 접속용 QR코드 자동 생성: 실제 배포 URL로 생성
- 최대 120명 참가(서버 사양에 따라 실질 동시 접속 가능 인원은 달라질 수 있음)

## 가장 간단한 공개 배포: Render

**중요:** ZIP 파일 자체는 공개 웹사이트가 아닙니다. Render 등 호스팅에 올린 후에 공개 URL이 생깁니다.

1. https://github.com 에서 새 저장소를 만들고 이 폴더의 파일들을 업로드합니다. ZIP 파일을 통째로 업로드하지 말고 압축 해제한 **폴더 내부 파일들**을 업로드하세요.
2. https://dashboard.render.com 에 로그인한 뒤 **New → Blueprint**를 선택합니다.
3. GitHub 저장소를 연결하고 `render.yaml`을 선택해 배포합니다. `TEACHER_PIN` 환경변수 입력 요청이 나타나면 **직접 6자리 이상의 교사 비밀번호**를 설정하세요. 학생에게는 알려주지 마세요.
4. 설정한 교사 비밀번호를 별도로 보관하세요. 변경하려면 Render 서비스의 **Environment** 메뉴에서 `TEACHER_PIN`을 수정하고 재시작합니다.
5. Render에서 발급된 `https://...onrender.com` 주소가 공개 접속 링크입니다. 주소 끝에 `/`를 붙여도 됩니다.
6. 교사 화면에서 **링크 / QR** 버튼을 누르면 실제 공개 주소의 QR코드가 표시됩니다. 화면을 캡처하거나 인쇄해 학생들에게 보여주세요.

### 교사 사용법
1. 링크 접속 → **선생님 진행 화면** → `TEACHER_PIN` 입력.
2. **링크 / QR** 버튼을 눌러 학생에게 참가 주소를 보여주세요.
3. 학생이 이름/별명으로 참가하면 **1번 문제 시작**을 누릅니다.
4. 각 문제는 25초 후 자동으로 정답 공개되며, 4.5초 후 다음 문제로 넘어갑니다. 교사는 **정답 공개** 또는 **다음 문제** 버튼으로 직접 진행할 수도 있습니다.
5. 24문제 후 최종 랭킹을 확인합니다. **새 게임 시작**을 누르면 참가자와 점수가 초기화됩니다.

### 로컬 실행 (개발자용)
```bash
npm install
npm run build
TEACHER_PIN=12345678 npm start
```
`http://localhost:3000` 에 접속합니다. 개발 모드는 터미널 두 개에서 `TEACHER_PIN=12345678 npm start` 및 `npm run dev`를 실행하고 `http://localhost:5173`으로 접속할 수 있습니다.

## 운영 시 유의사항
- 무료 Render 서비스는 장시간 미사용 시 일시 정지되거나 재시작될 수 있습니다. 이 경우 첫 접속이 느릴 수 있습니다.
- 게임/참가자 상태는 **서버 메모리**에만 저장됩니다. 서버가 재시작되면 진행 중 게임과 점수는 초기화됩니다.
- 서버 인스턴스는 하나로 유지해야 합니다. 여러 인스턴스에 분산하면 같은 게임 상태가 공유되지 않습니다.
- 이 버전은 교실 내 재미있는 실시간 게임을 위한 것으로, 정식 시험/부정행위 방지 시스템은 아닙니다.
- QR코드는 실제 배포 주소가 정해진 후 교사 화면에서 자동 생성됩니다. 배포 전에는 공용으로 스캔 가능한 QR코드를 발급할 수 없습니다.
