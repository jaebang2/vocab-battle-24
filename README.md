# 어휘 배틀 — 반별 독립 · 개인 속도 경쟁 · 문제 등록형

## 기능
- 교사별 계정: Render 환경변수 `TEACHER_ACCOUNTS`에 JSON 배열 등록
- 교사마다 독립된 6자리 반 코드와 별도 참가자·순위
- 교사 시작 후 학생마다 각자 속도로 문제 풀이, 정답을 맞혀야 다음 문제로 이동
- 오답은 재선택할 수 없고, 정답까지 여러 번 시도 가능
- 완주 시간 우선 순위, 진행 중에는 푼 문제 수 우선; 오답 수·시도 횟수·점수 표시
- 교사 진행 중 초기화, 실시간 참가 명단 및 QR
- 엑셀에서 문제 설명·보기 4개·정답 6열을 복사해 교사 화면에 붙여넣어 1~100문제 등록
- 기존 24문제는 기본 콘텐츠

## Render 환경변수 예시
`TEACHER_ACCOUNTS` = `[{"id":"teacher1","name":"김 선생님","password":"개별_비밀번호_6자이상"},{"id":"teacher2","name":"이 선생님","password":"다른_비밀번호_6자이상"}]`

교사 비밀번호는 GitHub 코드에 넣지 말고 Render 환경변수에만 입력하세요. 기존 `TEACHER_PIN`만 설정하면 `teacher` 계정으로 로그인하는 이전 방식도 지원합니다.

## 배포
기존 GitHub 저장소의 파일을 교체하고 Render가 재배포되도록 합니다. Build Command는 `npm install --include=dev && npm run build`, Start Command는 `npm start` 입니다. 프로젝트 최상위의 `server`, `src`, `package.json`, `render.yaml`, `index.html`, `vite.config.js` 파일을 올리세요.

## 문제 입력
엑셀 6열을 사용합니다: `문제 설명 | 보기1 | 보기2 | 보기3 | 보기4 | 정답` (파이프는 설명용이며 실제로는 **탭**으로 구분합니다). 첫 행 제목은 제외하고 복사하세요. 보기와 정답의 띄어쓰기까지 동일해야 합니다. 새 문제를 등록하기 전에 교사 화면에서 초기화하여 참가자를 비우세요.

## 중요 제한
- 무료 Render 인스턴스의 **메모리**에 게임 상태와 등록 문제가 저장됩니다. 재시작·휴면·재배포 시 데이터와 반 코드가 사라질 수 있습니다. 수업 전 반드시 확인하세요.
- 교사 계정은 Render 관리자 환경변수로 추가합니다. 교사가 사이트에서 직접 가입하거나 영구적으로 문제를 저장하는 완전한 SaaS 플랫폼은 아닙니다.
- 학생들은 같은 문제를 같은 순서로 풀지만, 학생별로 진행 속도가 다릅니다.
- 순위는 완주한 학생을 먼저 완주 시간 순으로, 미완주 학생은 해결한 문제 수·오답 수·점수 순으로 표시합니다.
- 별도의 데이터베이스, 교사 셀프 회원가입, 영구 저장, 콘텐츠 자동 문제 생성, 운영자 결제/구독 관리는 향후 확장 사항입니다.

## 로컬 테스트
`npm install` → `npm test` → `npm run dev` (프런트 개발) / `npm run build && npm start` (서버 실행)
